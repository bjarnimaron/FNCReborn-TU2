## FNC Reborn 1.0

The first release of FNC Reborn, a native Windows port of Fight Night Champion
(Xbox 360).

- Fight Now, Legacy mode, Champion mode, Create a Fighter, saving and loading,
  with sound.
- 60 FPS by default; 30, 120 and 144 in the new Settings > DISPLAY tab, along
  with VSync, resolution scale, anti-aliasing and fullscreen.
- A camera behind your boxer: press Back on the controller (or F2).
- Older CPUs get a compatible build automatically.

## Install or update

1. Download **FNCReborn-Setup.exe** below and run it.
2. New install: choose your Fight Night Champion (Xbox 360) disc image (.iso)
   or game folder and an install folder, then press **Install**.
   Update: choose your FNC Reborn folder and press **Update**. Only what
   changed is rebuilt; your saves and settings are kept.

Setup downloads everything else it needs (about 2.5 GB of build tools, kept
in the install folder; no Visual Studio needed). The first build takes 15-60
minutes depending on your CPU. Avoid installing inside a OneDrive folder;
syncing can break the build.
